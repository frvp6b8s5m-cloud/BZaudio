# BZaudio — Built to Be Heard

A responsive, cinematic single-page website for BZaudio. The visual direction uses a dark studio palette, warm amber accents, editorial typography, custom CSS illustrations, restrained motion, and reduced-motion accessibility support.

## Files

- `index.html` — page content and sections
- `styles.css` — visual design, responsive layouts, animations
- `app.js` — mobile navigation, reveal effects, contact inquiry form

## Preview locally

Open `index.html` in a browser, or use a simple local static server.

## Before launch

1. Replace the temporary BZ typographic mark with the approved BZaudio logo when its image file is available.
2. Set the contact form's `data-contact-email` attribute in `index.html` to the inbox that should receive inquiries. Until configured, the form deliberately does not pretend to send email.
3. Configure the hosting provider to publish the repository's root directory.
4. The separate `/admin` product/service manager is a future phase and must be protected with real authentication and a backend before handling private data. Do not treat a static HTML page as secure access control.
