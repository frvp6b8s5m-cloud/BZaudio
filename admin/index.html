Product format

Example catalog entry

The catalog is a JSON list. Add each item as an object inside the square brackets, separating multiple objects with commas. Use real product details and confirmed prices only.

[
  {
    "name": "Product name",
    "category": "Speakers",
    "description": "Short, accurate product description.",
    "price": "$0.00",
    "image_url": "https://example.com/product-image.jpg",
    "product_url": "https://example.com/product-page"
  }
]

The price, image_url, and product_url fields are optional. If product_url is omitted, the product card offers an email inquiry instead. Changes on GitHub trigger the site's deployment workflow.
